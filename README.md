## About Me

안녕하세요. React와 TypeScript를 기반으로 웹 제품을 개발하는 6년차 프론트엔드 엔지니어 윤성국입니다.

B2C 웹과 WebView, 운영 Admin, 의료기관 대상 엔터프라이즈 제품을 개발했습니다. 사용자 기능부터 운영 도구까지 제품의 여러 흐름을 경험했으며, 현재는 의료영상 뷰어 SDK와 이를 활용하는 웹 제품을 만들고 있습니다.

코드를 작성할 때는 동작 여부뿐 아니라 변경 전후의 결과를 확인할 수 있는 기준을 함께 만듭니다. 운영 중 발견한 문제는 테스트와 자동화에 반영하고, 해결 과정은 문서로 남겨 재발 가능성을 줄입니다.

## What I Do

- **제품 개발**: React·Next.js·TypeScript로 B2C 웹, WebView, 운영 Admin과 B2B 엔터프라이즈 제품을 개발합니다.
- **상태와 데이터 흐름**: TanStack Query로 서버 상태를 관리하고, Zustand·Redux·Jotai를 제품 규모와 상태의 성격에 맞게 사용합니다.
- **Web–App 연동**: 소셜 로그인·본인인증·공공 데이터 연계를 개발하고, WebView와 앱의 통신 인터페이스를 표준화했습니다.
- **컴포넌트 설계**: 반복되는 UI 패턴을 재사용 가능한 컴포넌트로 만들고 Storybook을 통해 디자이너·기획자와 동작 기준을 공유합니다.
- **품질 자동화**: 실제 장애와 회귀 사례를 테스트로 전환하고, Vitest·Testing Library·Playwright 검증을 CI에 연결합니다.
- **성능과 접근성**: 번들·렌더링 비용을 측정하고 지연 로딩·폰트·이미지를 최적화하며 Lighthouse와 브라우저 테스트로 확인합니다.
- **라이브러리 개발**: 제품에서 공통으로 사용하는 기능을 npm 패키지로 구성하고 버전·의존성·변경사항을 관리합니다.
- **개발 문서**: 여러 서비스의 기술 문서와 의사결정 기록을 한곳에 모아 팀이 같은 기준을 참고할 수 있도록 관리합니다.
